JARVIS: a voice-first AI assistant

JARVIS is an assistant you can talk to in a terminal, a desktop HUD, or this browser interface. It talks to an OpenAI-compatible language model, remembers recent conversation, and runs real desktop commands like opening the browser, creating files, and running Python.

Highlights

  • Hands-free “Hey Jarvis” wake phrase using the Web Speech API
  • Spoken replies through speech synthesis
  • Command parser and executor for browser, file, code and search actions
  • Rolling conversation memory stored as JSON, no database
  • Falls back to a local responder when no API key is set
  • Zero-build frontend: plain HTML, CSS and JavaScript

Architecture

  1. Browser UIvoice, transcript, HUD
  2. Python HTTP serverstandard library, /chat
  3. JarvisAssistantparser → executor → memory
  4. LLM clientany OpenAI-compatible API

Stack

About this demo

The public version runs in demo mode. Replies come from a built-in script, and commands are simulated, so nothing runs on your machine. Run the project locally to connect the live Python backend.
